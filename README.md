# 🎵 BotMusicDiscord

Un bot de musique Discord avancé avec Lavalink, créé par **Rayan elhabib (skz_rayan23)**.

## ✨ Fonctionnalités

- 🎶 **Lecture de musique** - Support YouTube, Spotify, SoundCloud
- 🔄 **Playlists** - Gestion des playlists personnalisées
- 📊 **Statistiques** - Suivi des écoutes et favoris
- 🎨 **Interface moderne** - Commandes slash et embeds élégants
- ⚡ **Performance optimisée** - Utilisation de Lavalink pour une qualité audio parfaite

## 🚀 Installation

1. **Cloner le projet**
```bash
git clone https://github.com/rayanelhabib/BotMusicDiscord.git
cd BotMusicDiscord
```

2. **Installer les dépendances**
```bash
npm install
```

3. **Configuration**
```bash
cp config.example config.js
# Éditer config.js avec vos tokens
```

4. **Démarrer Lavalink**
```bash
npm run start:lavalink
```

5. **Démarrer le bot**
```bash
npm start
```

## 📋 Prérequis

- Node.js 18.0.0 ou plus récent
- Java 11+ pour Lavalink
- Token Discord Bot
- Token Spotify (optionnel)

## 🎮 Commandes

### Musique
- `$play <musique>` - Jouer une musique
- `$skip` - Passer la musique
- `$stop` - Arrêter la musique
- `$pause` - Mettre en pause
- `$resume` - Reprendre
- `$queue` - Voir la file d'attente

### Playlists
- `$playlist create <nom>` - Créer une playlist
- `$playlist add <nom> <musique>` - Ajouter à une playlist
- `$playlist play <nom>` - Jouer une playlist

### Statistiques
- `$stats` - Voir vos statistiques
- `$top` - Top des musiques
